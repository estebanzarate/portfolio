# cv

Personal portfolio and resume built as a web app, featuring live HackTheBox stats.

## Stack

- React + Vite
- Tailwind CSS

## Features

- About, experience, education and skills sections
- HTB Machines — filterable table with stats by OS and difficulty
- HTB Academy — module progress with category breakdown

## Getting Started

```bash
npm install
npm run dev
```

## Updating HTB Data

The `src/data/academy.json` and `src/data/machines.json` files are generated by separate scripts and updated manually. Rebuild after updating them to reflect changes.

## Deploy

```bash
npm run build
```

Output is in `dist/`, ready to serve on any static host (Vercel, Netlify, GitHub Pages, etc.).
